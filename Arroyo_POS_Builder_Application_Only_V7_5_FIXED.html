📱Step 6 — Install as a Real App

🎉 Your app bundle is ready

These files turn your POS into an installable app. Upload them to a free GitHub Pages site, then anyone can open the link and tap Add to Home Screen — it gets your logo as its icon, opens without a browser bar, and keeps working offline.

Unzip it, then drag all the files into your repository.
Files in the bundle
App icon (from your logo)
Didn't upload a logo? Your emoji is used on your accent colour instead. Go back to Step 2 to add one.
sw.js — copy & paste
On GitHub: Add file → Create new file, name it sw.js, paste, commit.
manifest.json — copy & paste
Your app link
Taken from Step 4c. Every path inside these files is relative, so the bundle works at whatever address you end up using — this is just the link to open on the phone.
https://<username>.github.io/<repo>/
Open that on the phone, then use Add to Home Screen.
Put it on GitHub Pages (free)
1
Create a repository
On github.com/new, give it a name like my-pos, set it to Public, and click Create repository.
2
Upload every file
Click uploading an existing file, then drag in all the files — index.html, manifest.json, sw.js and the four .png icons. Commit.
Everything sits side by side, with no folders to keep. Open the unzipped folder and select what's inside it — dragging the folder itself puts everything one level too deep and the address shows a 404.
The icons are not optional: without icon-192.png and icon-512.png the browser will refuse to install the app.
3
Switch Pages on
Settings → Pages. Under Branch pick main and / (root), then Save. Wait a minute or two for the green tick.
4
Open the link on the phone
Your address looks like https://username.github.io/my-pos/. Open it in Chrome (Android) or Safari (iPhone).
5
Install it
Android: tap the menu → Install app / Add to Home screen. iPhone: tap Share → Add to Home Screen. Your logo becomes the app icon.
💡 Updating later: regenerate here, upload the new index.html and sw.js over the old ones. Each build carries a new cache name, so phones pick up the change on the next open. Sales already recorded on a device are kept.
