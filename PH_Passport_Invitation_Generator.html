Step A — Create a free account

1Go to emailjs.com ↗ → click Sign Up Free
2Verify your email and log in to the dashboard

Step B — Connect your email (Gmail / Outlook)

1In the dashboard, click Email Services ↗
2Click Add New Service → choose Gmail or Outlook
3Follow the prompts to connect your account → click Create Service
4Copy the Service ID shown (looks like service_abc1234)

Step C — Create an email template

1Click Email Templates ↗ → Create New Template
2Set these fields exactly:
To Email: {{to_email}}
From Name: {{from_name}}
From Email: {{from_email}} ▲ uncheck "Use Default"
Subject: {{subject}}
Reply To: {{reply_to}}
Content: {{{message}}} ▲ 3 curly braces!
3Click Save
4After saving, you'll see the Template ID in the URL bar:
dashboard.emailjs.com/admin/templates/template_xxxxxxx
— copy that ID (starts with template_)
⚠ Common error: "Template ID not found"
This means the Template ID was copied incorrectly. Go to emailjs.com/admin/templates ↗, open your template, and copy the ID from the page URL. It must start with template_
Why 3 braces? EmailJS uses {{{message}}} (triple) to render raw HTML. With only 2 braces the passport design will show as broken code instead of the invitation.

Step D — Get your Public Key

1Click Account → General ↗
2Copy the Public Key shown at the top of the page
Account → General → Public Key
Remember: use {{{message}}} (3 braces) in the template body
Generate client website
Everything is pre-filled and locked. The client just opens their website and clicks Send All. No editing needed.

How to deploy to GitHub Pages

1Click Generate & Download below — you get one index.html file
2Go to github.com ↗ → New repository → name it anything
3Upload the index.html file → commit
4Go to Settings → Pages → Deploy from branch → main
5Share the URL username.github.io/repo-name with the client
